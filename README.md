# JAVA-DSA-PROGRAMMING

A collection of Java implementations for common Data Structures and Algorithms (DSA) problems and examples. This repository is organized to help learners study core DSA concepts using clear, simple Java code.

## Repository structure

- arrays/
- strings/
- linkedlists/
- stacks/
- queues/
- trees/
- graphs/
- sorting/
- searching/
- dynamic-programming/
- utils/ (helper classes)

## How to run

1. Ensure you have Java (JDK 8+) installed.
2. Compile a Java file from the repository root:
   javac path/to/FileName.java
3. Run the compiled class (use the fully-qualified package name if present):
   java path.to.ClassName

Alternatively, import the project into an IDE (IntelliJ IDEA, Eclipse) and run from there.
