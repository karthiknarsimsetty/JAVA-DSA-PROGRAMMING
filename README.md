# JAVA DSA PROGRAMMING

Sample collection of Java programs demonstrating common data structures and algorithms. This repository is intended for learning and teaching basic DSA concepts in Java.

Contents:
- src/ArraySum.java — simple array operations and sum
- src/BinarySearch.java — iterative binary search example
- src/LinkedListExample.java — singly linked list with insert/delete
- src/stack/StackExample.java — stack implemented with array
- src/queue/QueueExample.java — queue implemented with array

Build and run
1. Compile all Java files:
   javac -d out src/*.java src/stack/*.java src/queue/*.java
2. Run an example (e.g., BinarySearch):
   java -cp out BinarySearch

Notes
- These examples use the default package for simplicity. For real projects, add a package (e.g., com.yourname.dsa) and update paths.
- Contributions welcome: open PRs with improvements or new examples.
